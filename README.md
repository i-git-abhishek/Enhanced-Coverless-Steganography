# Enhanced Coverless Steganography

Baseline reproduction of Lin & Liang, "A Coverless Image Steganography Technique Based on Multi-Object Mapping Rules," IEEE Transactions on Multimedia, vol. 28, 2026.

**Start with [MANUAL.md](MANUAL.md).** It covers setup, running on Kaggle, changing n and M, saving results and changing code.

```text
run.py                        Command line for everything
configs/                      One settings file per dataset
stego/                        The method, attacks, evaluation and run tracking
tests/                        Automated tests, including the paper's worked examples
notebooks/kaggle_baseline.ipynb   Notebook to run on Kaggle
experiments/runs/             Saved runs, committed to Git
experiments/RESULTS_DASHBOARD.md  Generated summary of all runs
legacy/                       Old code behind Exp01. Invalid, kept only as a record
```
